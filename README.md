# IT quiz web app

This was a school project, where we had to create a website using PHP. The task was to make an IT programming quiz web application.

## Features
- Clean UI
- Different types of quizzes
- Randomly shows quizzes
- Provides with a result at the end of the quiz
- Admin page where quizzes can be managed

## Technologies
Frontend: HTML,CSS,JavaScript
Backend: PHP
Database: MySQL
